Chrome / Edge web-response notifications:
1. Run install_browser_bridge.ps1 in the app folder (or select the optional browser-bridge installer task).
2. Open chrome://extensions or edge://extensions and enable Developer mode.
3. Load the browser_extension folder as an unpacked extension.
4. Open its popup, explicitly enable detection, and click the connection test. Refresh existing AI tabs.
Only a completion signal is sent to the local pet. Chat content and API keys are not read or transmitted.
Detection depends on site UI; errors, manual stops, and long intermediate pauses can be misclassified. Live authenticated providers have not been verified. Native AI desktop apps are not detected.

Local workflows: notify.ps1 / integrations/notify.py can send a signal after your own workflow actually completes.
No network listener or external AI model call is provided by that local bridge.
